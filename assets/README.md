# Assets Directory

This folder is reserved for static media assets. 

In this version of the project, all visual artwork (landscape, characters, lighting, flora, mist) and audio soundscapes (winter wind, bird songs) are **100% procedurally synthesized** at runtime using:
- **HTML5 Canvas 2D API** (`js/environment.js`, `js/characters.js`, `js/scene.js`)
- **Web Audio API** (`js/main.js`)

No external image or sound files are required to run the animation. Custom raster or audio assets can be placed in their respective subdirectories if needed for future extensions.
